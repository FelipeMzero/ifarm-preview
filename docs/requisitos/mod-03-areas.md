# 📦 Módulo: `MOD-AREAS`

Módulo responsável pelo gerenciamento das áreas de cada propriedade (fazenda). O módulo deve possibilitar consulta, criação e alteração dos dados de área, sendo que os limites de cada área devem ser desenhados sobre um mapa para tornar a sua identificação mais rápida e fácil. Cada área está vinculada a uma propriedade específica.
