# ADR-0004: Banco com Prisma em packages/db

- **Situação:** aceito
- **Data da decisão:** 23/10/2026
- **Data do registro:** 31/10/2026

## Contexto

O acesso ao banco ficava dentro do app web. Com a separação dos apps, o schema, o cliente gerado e o CLI precisavam de um lugar próprio.

## Decisão

O PostgreSQL é acessado pelo Prisma. `packages/db` guarda o schema, o cliente gerado, a instância do banco, a configuração do CLI e o container de desenvolvimento. Só a API usa esse pacote.

## Consequências

- As consultas são tipadas a partir do schema.
- Os clientes não têm como depender do banco.
- O diagrama ER é gerado a partir do schema.
