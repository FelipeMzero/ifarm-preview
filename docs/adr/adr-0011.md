# ADR-0011: Sessão de manejo como agrupadora de etapas

- **Situação:** aceito
- **Data da decisão:** 26/09/2026 (etapas em tabelas: 02/10/2026)
- **Data do registro:** 31/10/2026

## Contexto

Um manejo costuma tratar vários animais de uma vez, com várias etapas (pesagem, identificação, castração, sanitário, apartação). Os mesmos fatos também podem ser registrados de forma avulsa.

## Decisão

A sessão agrupa as etapas e os animais participantes. Cada registro fica na tabela definitiva do seu tipo (ex.: `AnimalWeighing`), a mesma dos avulsos, ligado à etapa da sessão, e só passa a valer quando ela é consolidada. As etapas ficam em tabelas. A recepção de uma compra usa uma sessão de manejo.

## Consequências

- O histórico do animal tem um único lugar para cada tipo de registro, com filtros de registro efetivo (`effective.public.ts`).
- Toda leitura precisa distinguir os registros efetivos dos pendentes.
- Um novo tipo de etapa entra no registro `STEP_MODULES`: ver o guia [Tipo novo de etapa de manejo](../guides/nova-etapa-de-manejo.md).
