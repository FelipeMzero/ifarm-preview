# ADR-0007: Schemas Zod no shared como contrato único

- **Situação:** aceito
- **Data da decisão:** 22/10/2026
- **Data do registro:** 31/10/2026

## Contexto

Os clientes e a API precisam validar os mesmos dados, sem regras divergentes nem tipos escritos à mão.

## Decisão

Os schemas Zod do que o cliente envia ficam em `packages/shared`. A API valida as requisições com eles, e os formulários, com `zodResolver`. Os tipos vêm dos schemas (`XPayload = z.input`, `XData = z.output`).

## Consequências

- Uma regra de validação é escrita uma vez e vale nos dois lados.
- Tudo no `shared` é público e roda nos clientes: ele não pode ter segredos, decisões de negócio nem dependências de Prisma ou Node.
- Um app móvel antigo pode rodar um contrato desatualizado, por isso o servidor sempre revalida.
