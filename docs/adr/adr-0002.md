# ADR-0002: Web como SPA em React e Vite, com TanStack Query

- **Situação:** aceito
- **Data da decisão:** 23/10/2026 (TanStack Query: 24 e 25/10/2026)
- **Data do registro:** 31/10/2026

## Contexto

Com a API separada em um app próprio, o web deixou de precisar de um servidor que acessasse o banco. Ele era uma aplicação Next.js e passou a conter só telas.

## Decisão

`apps/web` é uma SPA em React e Vite, com rotas no React Router. Os dados das telas vêm da API pelo TanStack Query. Em desenvolvimento, o Vite repassa `/api/*` para a API.

## Consequências

- O web não acessa o banco e não contém regras de negócio.
- Cache, recarga e estado das requisições ficam concentrados no TanStack Query.
- O web depende da API para qualquer dado.
- Substitui o uso do Next.js adotado no início do projeto.
