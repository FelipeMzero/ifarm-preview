# ADR-0005: Código e API em inglês; português nas telas, nas URLs de página e nos comentários

- **Situação:** aceito
- **Data da decisão:** 11/07/2026
- **Data do registro:** 31/10/2026

## Contexto

O projeto misturava termos em português e em inglês, e o domínio é descrito em português nos requisitos.

## Decisão

Nomes de código, banco e API ficam em inglês (`/api/batch`). Telas, mensagens ao usuário, URLs de página (`/lotes`) e comentários ficam em português. O mesmo nome de domínio é usado em todas as partes.

## Consequências

- Cada conceito tem um único nome no código.
- É preciso manter a correspondência entre os termos dos requisitos e os do código.
