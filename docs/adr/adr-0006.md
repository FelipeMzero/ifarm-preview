# ADR-0006: Autenticação com better-auth

- **Situação:** aceito
- **Data da decisão:** 11/07/2026
- **Data do registro:** 31/10/2026

## Contexto

O sistema precisa autenticar usuários no web e no mobile e controlar o acesso por papel.

## Decisão

A autenticação usa better-auth, com e-mail e senha e sem cadastro aberto. O servidor fica em `apps/api/src/auth.ts`, grava no banco pelo adaptador do Prisma e usa os plugins `admin` (papéis) e `expo` (mobile).

## Consequências

- As tabelas `User`, `Session`, `Account` e `Verification` seguem o formato da biblioteca.
- As permissões ficam em `RESOURCE_ACCESS`: a API as usa para negar, e as telas, para esconder.
- Atualizações da biblioteca podem exigir mudanças nessas tabelas.
