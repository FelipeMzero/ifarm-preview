# ADR-0010: Fronteiras entre fatias e domínios garantidas por lint

- **Situação:** aceito
- **Data da decisão:** 28/10/2026
- **Data do registro:** 31/10/2026

## Contexto

Sem uma verificação automática, as fatias verticais ([ADR-0003](adr-0003.md)) tendem a se acoplar com o tempo.

## Decisão

As regras `ifarm/slice-boundary` e `ifarm/domain-boundary`, em `apps/api/eslint.config.mjs`, geram erro nas violações. O que está na pasta de uma fatia é só dela. O nível do domínio é comum às fatias dele. Outro domínio só importa arquivos `*.public.ts`.

## Consequências

- As dependências entre domínios ficam explícitas nos arquivos `*.public.ts`.
- Usar algo interno de outro domínio exige movê-lo para um desses arquivos.
