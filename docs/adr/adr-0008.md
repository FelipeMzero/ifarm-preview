# ADR-0008: Separação de schema.ts, types.ts e client.ts no shared

- **Situação:** aceito
- **Data da decisão:** 28/10/2026
- **Data do registro:** 31/10/2026

## Contexto

O contrato de cada domínio reúne o que o cliente envia, o que a API responde e as chamadas HTTP.

## Decisão

Cada domínio de `packages/shared` tem `schema.ts` (o que o cliente envia), `types.ts` (o que a API responde) e `client.ts` (as funções que chamam a API).

## Consequências

- Fica claro onde cada parte do contrato está.
- A API e os clientes tipam as respostas com os mesmos tipos.
- Os tipos de `types.ts` são escritos à mão, e o compilador só os confere onde a API os usa.
